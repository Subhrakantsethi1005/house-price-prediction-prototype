# Model Card

## Model Overview

This project trains a supervised regression model to predict synthetic house prices from property attributes such as size, rooms, bathrooms, location, amenities, furnishing status, and distance from the city center.

The model is intended as a portfolio-quality prototype that demonstrates a complete machine learning workflow:

- Dataset generation
- Data validation
- Preprocessing
- Model comparison
- Evaluation
- Model persistence
- Batch prediction
- Testing and CI setup

## Intended Use

This model is appropriate for:

- Learning and demonstrating regression workflows
- Portfolio presentation
- Testing ML project structure
- Experimenting with preprocessing and model comparison

This model is not appropriate for:

- Real-world property valuation
- Financial decisions
- Investment decisions
- Legal, lending, or insurance use

## Dataset

The dataset is synthetic and generated by [src/synthetic_data.py](src/synthetic_data.py).

The generator encodes realistic pricing relationships:

- Larger houses cost more.
- Downtown and waterfront homes receive premiums.
- Older properties generally cost less.
- Amenities and furnishing increase price.
- Greater distance from the city center reduces price.
- Random noise is added to avoid a perfectly deterministic target.

## Training Approach

The training script compares multiple regression models:

- Linear Regression
- Ridge Regression
- Random Forest Regressor
- GradientBoostingRegressor

The best model is selected by lowest mean absolute error on a holdout test set.

## Evaluation Metrics

The project reports:

- MAE
- RMSE
- R2
- MAPE

## Limitations

Because the data is synthetic, strong metrics do not prove real-world predictive power. They only show that the model can learn the relationships encoded in the generator.

The project is honest about this limitation and should be presented as a professional ML prototype rather than a production real-estate valuation tool.
